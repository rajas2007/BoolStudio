# Project Roadmap & Milestones

## 📍 Milestone 1: Initialization & Doc System
- **Objective**: Establish development standards, workspace setup, and architectural guidelines.
- **Priority**: High
- **Complexity**: Low
- **Dependencies**: None
- **Status**: Completed (2026-08-08)

## 📍 Milestone 2: Core Logic Builder
- **Objective**: Interactive canvas allows adding and connecting basic logic gates (AND, OR, NOT).
- **Features**:
  - Drag and drop gates
  - Port connectivity
  - Propagation loop
- **Priority**: High
- **Complexity**: Medium
- **Dependencies**: Milestone 1
- **Status**: Not Started

## 📍 Milestone 3: Storage & Simplification features
- **Objective**: Support local persistence and Boolean expression parsing/solving tools.
- **Features**:
  - `localStorage` export/import
  - Truth table generator
  - Boolean Algebra simplifying engine
- **Priority**: Medium
- **Complexity**: High
- **Dependencies**: Milestone 2
- **Status**: Not Started
