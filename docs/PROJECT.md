# Project Overview: BoolStudio

## 📖 Introduction
BoolStudio is a platform designed to design, visualize, and learn boolean logic. It enables users to build circuits, analyze truth tables, and understand digital logic principles dynamically.

## 🎯 Project Goals
- **Intuitive Design**: Allow users to drag, drop, and connect logic gates easily.
- **Dynamic Visualization**: Real-time evaluation of logic circuits and truth table generation.
- **Educational Value**: Step-by-step logic simplifications (Boolean algebra theorems, Karnaugh maps).

## 🛠 Tech Stack (To be defined/expanded)
- **Core**: HTML, CSS, JavaScript
- **Framework**: Vite / Next.js (as needed)
- **Styling**: Vanilla CSS
